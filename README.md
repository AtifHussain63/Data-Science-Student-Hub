 DataScience Student Hub

A modern web app to learn Data Science, AI & Programming with an AI Tutor powered by Google Gemini.

GitHub Repo Link:https://github.com/atifhussain63/data-science-student-hub.git

Live Demo: [data-science-student-hub-ui66.vercel.app](https://data-science-student-hub-ui66.vercel.app)

 Features

-  AI Tutor - Ask any Data Science question and get instant answers using Gemini API
-  Course Content - Python, SQL, Statistics, Machine Learning, Deep Learning
-  Interactive Quizzes - Test your knowledge after every topic
- Progress Tracking - Login with Firebase and track your learning
-  Responsive Design- Works perfectly on mobile and desktop
-  Fast - Built with Vite + React for blazing fast performance

 Tech Stack

Frontend:
- React 18 + Vite
- Tailwind CSS
- React Router

Backend & Auth:
- Firebase Authentication
- Firebase Firestore Database
- Firebase Hosting ready

**AI:
- Google Gemini API

Deploy:
- Vercel
